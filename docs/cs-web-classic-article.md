# 致敬经典：把《反恐精英》搬进浏览器，80、90后的青春又回来了

![游戏画面：地图中的CCTV13大屏与对战角色](../shots/cctv13-live-screen.png)

有些游戏，隔了二十多年，开一局还是能立刻找回手感。比如《反恐精英》。

80后、90后应该都记得：放学回家，书包往桌上一扔，电脑前一坐，耳机里先传来熟悉的脚步声。网吧里最热闹的地方，永远是那几台连着局域网的机器。有人在喊“Rush B”，有人蹲在门后阴人，还有人一把沙鹰打完，嘴上说“这枪有问题”，手却已经开始下一局。

那时候的快乐很简单。一张地图，几把枪，几个朋友，输赢都能吵半天。Dust2 的中门、Assault 的仓库、Italy 的小巷，闭着眼都能想起路线。多年以后再回头看，画面当然不算精致，甚至有点“像素味”，但那种紧张感、配合感，还有突然被闪光弹晃白的慌张，依然很真实。

我最近做了一个 CS Web 版，想做的事情也很朴素：不用装客户端，打开浏览器，就能重新走进那张熟悉的地图。

它保留了经典的第一人称操作：WASD 移动、跳跃、蹲下、换弹、买枪，AK、M4、AWP、沙鹰和三种手雷都安排上了。移动、后坐力、弹道散布、命中部位和护甲计算，都按老 CS 的味道来做。点射会更稳，扫射会飘；不压枪，准星真的会带你飞——只不过飞到墙上。

这次不只是“打靶”。游戏里有 BOT 回合、经济系统、C4 安装和拆除，CT、T 两边都有自己的目标。BOT 会巡逻、听枪声、找路线、守包点，偶尔也会做出一些很像真人的迷惑操作：刚才还在认真防守，下一秒突然跳起来撞墙，像极了当年网吧里那个键盘坏掉的队友。

![游戏画面：经典模型与地图场景](../shots/original-chicken.png)

我还塞了一点小彩蛋：地图里会随机出现小鸡，能走、会停、还能被打出一地鸡毛。Dust2 里甚至放了一块 CCTV13 大屏，边打边看新闻，多少有点“在虚拟网吧里看电视”的味道。

当然，它不是要替代记忆里的那台老电脑，也不是要把经典包装成什么高科技大作。它更像是一把钥匙：哪天你突然想起当年那句“最后一把”，茶余饭后，点开浏览器，就能再来一局。
