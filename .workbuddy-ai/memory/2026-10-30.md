# 2026-10-30

## 修复 GitHub Actions 桌面端打包失败（v0.1.0，run 41075016363）

- 现象：`desktop (windows-latest)` 与 `desktop (macos-latest)` 均在 `Build desktop package`（`pnpm make-bsp && pnpm tauri:build`）失败，耗时 3~4 分钟，仅报 `exit code 1`；`web-zip` 正常。
- 根因：`src-tauri/tauri.conf.json` 的 `bundle.icon` 只声明了 `icons/icon.png`，缺少 macOS 需要的 `.icns` 与 Windows 需要的 `.ico`，打包器报 `failed to bundle project: Failed to create app icon: No matching IconType`。该错误发生在 Rust release 编译完成之后、bundle 阶段，因此耗时较长且两平台同时失败。
- 修复：`pnpm dlx @tauri-apps/cli@^2 icon src-tauri/icons/icon.png` 生成全套图标；`bundle.icon` 改为 32x32/128x128/128x128@2x/icon.icns/icon.ico；删除生成的 android、ios 目录；恢复原始 icon.png 作为源图。
- 验证：本机 `pnpm dlx @tauri-apps/cli@^2 build` 成功产出 `src-tauri/target/release/bundle/macos/CS 1.5 Web.app`（CFBundleIconFile=icon.icns）。DMG 阶段在本机因沙箱禁止 hdiutil 挂载卷而失败，属环境限制，非项目问题。
- 结论：图标类资源必须提交到 Git，否则 CI 仍会失败。

## 环境注意

- 本机 `node` 被 WorkBuddy 的 safe-delete shim 包装，Vite 清空 `dist/`（>50 文件）会抛 `SAFE_DELETE_BULK_CONFIRM_REQUIRED`。复现 Tauri 构建前可先 `mv dist dist.bak` 绕过。
